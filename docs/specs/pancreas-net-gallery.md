# Pancreatic Neuroendocrine Tumour — Reference Galleries (`pancreas_net`)

Four side-drawer reference panels in `schemas/pancreas_net.json` (QMH `Endocrine-Pancreas-NET`, CAP Pancreas Endocrine 5.0.1.0, WHO 5th edition, AJCC 9th edition):
1. **`grade`** — WHO 5th grading of PanNET (G1–G3) vs PanNEC + ExpertPath links
2. **`functionalType`** — Functional vs non-functional PanNET & hereditary syndromes (MEN1, VHL, NF1) + ExpertPath links
3. **`extension`** — AJCC 9th staging landmarks (pT1–pT4, pM1a/b/c) + ExpertPath links
4. **`marginStatus`** — Procedure-specific pancreatic resection margins + ExpertPath links
