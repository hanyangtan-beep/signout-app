- Staging: the QMH page uses **AJCC 9th edition** (TNM 9, effective 2025): T unchanged from the 8th; N2 split into N2a (single ipsilateral mediastinal or subcarinal station) / N2b (multiple ipsilateral mediastinal stations); M1c split into M1c1 (multiple extrathoracic metastases, one organ system) / M1c2 (multiple organ systems); stage groups rearranged in IIA / IIB / IIIA / IIIB. 3. Histologic grade (page: G1–G4 / GX / Not applicable) — see house grade rule below
4. Spread through air spaces (STAS): Not identified / Present
5. Visceral pleura invasion: Not identified / PL0 / PL1 / PL2 / Cannot be determined
6. Lymphatic and / or vascular invasion: Not identified / Present / Present, lymphatic / arterial / venous / Cannot be determined
7. Tumor extension (long list: adjacent lobe, parietal pleura, chest wall …, main bronchus, atelectasis / obstructive pneumonitis to hilum, mediastinal structures, T4 structures)
8. Treatment effect: No known presurgical therapy / > 10 % residual viable tumour / ≤ 10 % / Cannot be determined
9. Bronchial margin; 10. Vascular margin; 11. Parenchymal margin (incl. lepidic / AIS options); 12. Other tissue margin(s)
13. Regional lymph nodes: "Specify the locations of involved lymph nodes."; number examined; number involved; extranodal extension
14. Distant metastasis (M1a / M1b / M1c1 / M1c2 descriptors)
15. Pathologic stage classification (AJCC 9e): TNM descriptors (m / r / y); pT; pN (incl. pN2a / pN2b); pM (incl. pM1c1 / pM1c2)
16. Additional pathologic findings (AAH, tumorlets, squamous dysplasia, DIPNECH, biopsy-site changes, granulomatous inflammation necrotising / non-necrotising, post-obstructive changes, fibrosis pattern, emphysema, other)
17. Additional notes

Note: the page uses "Tumor" and the PL0–2 scale only; parietal pleura sits under Tumor extension (→ T3). House text uses "tumour".

## Part (b) — `src/staging/lung.js`  (Size M)

Protocol `lung` registered in `src/staging/index.js` `PROTOCOLS`; `deriveTNM(values, 'lung')`, same result shape (`t, n, m, stageGroup, notes, origin`) as ovary.

- **pT** from invasive size (mm) — lepidic-only extent excluded (Check when total > invasive): Tis = AIS / SCIS; T1mi = MIA (≤ 30 mm total, ≤ 5 mm invasion); T1a ≤ 10; T1b > 10–20; T1c > 20–30; T2a > 30–40 or ≤ 40 with visceral pleura (PL1–2) / adjacent lobe / main bronchus / atelectasis-to-hilum; T2b > 40–50; T3 > 50–70 or ≤ 70 with parietal pleura / chest wall / pericardium / phrenic nerve / azygos vein / thoracic nerve roots / stellate ganglion / separate nodule(s) same lobe; T4 > 70 or invasion of mediastinum (except T3 structures) / thymus / trachea / carina / recurrent laryngeal or vagus nerve / oesophagus / diaphragm / heart / great vessels / supra-aortic / brachiocephalic / subclavian vessels / vertebral body / lamina / spinal canal / cervical nerve roots / brachial plexus, or separate nodule(s) in a different ipsilateral lobe. Highest rule wins.
- **pN** from the station table (see (c)): N0 all negative; N1 stations 10–14 ipsilateral; N2a one ipsilateral mediastinal station (2–9, incl. 7 subcarinal); N2b ≥ 2 ipsilateral mediastinal stations; N3 any contralateral mediastinal / hilar or any scalene / supraclavicular (station 1); NX no nodes; N0(i+) not used in lung. Direct extension into a node counts as N1.
- **pM**: M1a pleural / pericardial nodules, malignant pleural / pericardial effusion, separate nodule(s) contralateral lobe; M1b single extrathoracic metastasis in one organ system (incl. single non-regional node); M1c1 multiple in one organ system; M1c2 multiple organ systems. Absent → no pM printed (cM0 assumed in the stage group).
- **Descriptors**: `y` when treatment effect ≠ "No known presurgical therapy"; `m` when the user marks multiple primaries; `r` recurrent.
- **Stage groups (9th)** — Tis N0 → 0; T1mi / T1a N0 → IA1; T1b N0 → IA2; T1c N0 → IA3; T2a N0 → IB; T2b N0 or T1 N1 → IIA; T2 N1, T3 N0, T1 N2a → IIB; T3 N1, T4 N0/N1, T1 N2b, T2 N2a, T3 N2a → IIIA; T2 N2b, T3 N2b, T4 N2a/N2b, T1–2 N3 → IIIB; T3–4 N3 → IIIC; M1a / M1b → IVA; M1c1 / M1c2 → IVB.
- **Override**: `tnmOverride` parser extended for `T1mi`, `N2a/b`, `M1c1/2`, printed `[pathologist override; derived …]` as in ovary.
- **Partial input** (engine item 3): `deriveTNM` accepts `{ prior: { t: 'pT1a', accession, procedure } }` and returns `origin: { t: 'prior', n: 'current' }`; `stageLine` prints `pT1a (prior wedge resection S26-01234) pN0 (0/8, this lobectomy)`.
- Boundary tests: 10 / 20 / 30 / 40 / 50 / 70 mm both sides; PL1 upgrades ≤ 40 mm to T2a but not > 40; same-lobe nodule T3 vs other-lobe T4 vs contralateral M1a; one vs two mediastinal stations; station 7 alone = N2a; contralateral hilar = N3; MIA > 5 mm invasion → T1a; AIS > 30 mm → not Tis (Check); every stage-group cell from the table.
